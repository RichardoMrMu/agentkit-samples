# 组合任务

按客户目标组合资源查询、申请、发送和结果分析。发送任务可先查询现有资源，
缺少适用资源时再办理所需申请；单独的资源办理或查询直接进入对应能力。

- 申请资源：资质、签名和引流录入默认使用 [表单](form-display.md)；模板按 [申请契约](application-contracts.md) 预览确认后提交。
- 报备进度：按 [报备查询](report-status.md) 取得签名或模板的适用范围，查询各运营商状态。
- 单条发送：补齐变量，用 `send-preview` / `send-submit` 确认并提交，按 Message ID 查结果。
- 群发：按 [群发流程](batch-form.md) 确认发送时间、打开表单并读取结果。
- 分析：按客户要求选择时间、范围和分组；聚合统计用于汇总，发送记录用于逐条排查，见 [发送契约](delivery-contracts.md)。

申请进度、审核状态和发送结果分别按对应接口返回解释。

正文或变量含链接、联系号码时，可按需使用 [引流能力](traffic-driving.md)。
